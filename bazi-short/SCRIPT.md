## 事实与出处（脚本里每个说法都要能对上这里）

| # | 事实 | 出处 | 可信度 |
|---|---|---|---|
| F1 | 古代聘娶婚走“六礼”：纳采、问名、纳吉、纳征、请期、亲迎。“问名”拿到女方信息后回去占卜，“纳吉”是得了吉兆再通知女方、定下婚约。 | 《仪礼·士昏礼》及郑玄注；概述见 [儒家网](https://www.rujiazg.com/article/32053)、[人民论坛](https://paper.people.com.cn/rmlt/html/2023-07/01/content_26011443.htm) | 高（经典文献） |
| F2 | 八字 = 出生的年、月、日、时四“柱”，每柱一个天干、一个地支，共八个字。 | [Wikipedia: Four Pillars of Destiny](https://en.wikipedia.org/wiki/Four_Pillars_of_Destiny) | 高 |
| F3 | 唐代李虚中（761–813）用生年月日的干支推命，韩愈为他写的墓志铭里记了这件事；宋代徐子平改以日干为“命主”，成为后来八字的主流算法。 | 韩愈《殿中侍御史李君墓志铭》；[澎湃新闻](https://www.thepaper.cn/newsDetail_forward_1305752)；Wikipedia 同上 | 高（李虚中）／中（三柱到四柱的细节各家说法不一，脚本里不提） |
| F4 | 庚帖（八字帖）：用红纸写生辰八字，由媒人送到男方家。男方把它供在神明厅或祖宗厅，三五天内家中平安、没出不吉利的事，亲事才继续。 | 台湾教育部客语辞典礼俗条目“合婚”“庚書”（hakkadict.moe.edu.tw；本会话网络打不开原 PDF，内容取自搜索摘要） | 中高 |
| F5 | 子平八字里，日柱的地支叫“夫妻宫”；另外男命看财星、女命看官星。 | 命理通行说法，见 [masterseanchan](https://www.masterseanchan.com/zh-hans/blog/%E5%A6%82%E4%BD%95%E5%88%A4%E6%96%AD%E4%BD%A0%E7%9A%84%E5%85%AB%E5%AD%97%E5%91%BD%E7%9B%98%E6%98%AF%E5%90%A6%E7%9B%B8%E5%90%88/)、[网易](https://m.163.com/dy/article/GOEC2FO90519AKDF.html) | 中（是“命理说法”这件事可信，不代表它灵验） |
| F6 | 民间婚配表主要按生年地支（属相）的六冲、三刑、六害来判断，例如子（鼠）午（马）相冲。十二地支每个都有一个六合、一个六冲、一个六害，并且都落在某一种“刑”里（子卯、寅巳申、丑戌未、辰午酉亥自刑）。 | 客语辞典“合婚”条（并注明“不足採信，請勿迷信”）；地支合冲刑害为通行规则 | 高（规则本身） |
| F7 | 民间合婚口诀：“白马怕青牛，羊鼠一旦休……”（各地版本字句略有不同）。 | [看中国](https://www.secretchina.com/news/gb/2022/11/09/1018598.html)、[uptogo](https://uptogo.com.tw/?p=1597043) | 中（口诀流传广，没有权威出处） |
| F8 | 现代汉语里“八字不合”常被引申为两人或两样东西合不来（如“我和数学八字不合”）。 | 日常用法 | 高 |

**立场：** 全片讲的是“传统和命理里怎么说”，不说它能预测婚姻。旁白一律用“命理里”“民间”“口诀说”这类说法。
**不用的说法：** “庚帖压在灶台下、打碎碗就退婚”只找到一条网友回忆，不进旁白。结尾的猫和碗只是画面笑点，接的是 F8 的现代用法。

## 脚本（中文旁白，语气平稳，约 300 字 ≈ 65 秒）

| 段落 | 旁白 | 画面（不重复旁白已经说的内容） |
|---|---|---|
| **钩子** | 两个人还没见面，婚事就先被八个字否了。 | 红纸庚帖从天而降，盖住镜头；白闪。 |
| **背景** | 清朝，江南小镇。媒人揣着一张红纸——庚帖，上面写着姑娘的生辰八字。 | 粉墙黛瓦、石拱桥、乌篷船、红灯笼；媒婆头戴红花，一路小跑过桥，怀里鼓着一块。 |
| **动作 1** | 年、月、日、时，各配一个天干、一个地支。四根柱子，正好八个字。 | 镇中心的石板地里“咚咚咚咚”升起四根红木柱，每根柱身上刻两个字。 |
| **动作 2** | 男方把它供在祖宗牌位前。三五天里家宅平安，亲事才往下走。 | 香案上摆着庚帖。一家人踮脚走路；一只橘猫蹲在碗柜边。父亲盯着猫，猫盯着碗。 |
| **动作 3** | 再请算命先生合婚：先看属相冲不冲，再看日柱的地支——命理里叫它“夫妻宫”。 | 算命先生坐在“铁口直断”布幡下，戴圆眼镜；两张庚帖并排摆好，日柱那根小柱子亮起来。 |
| **动作 4** | 民间还有口诀：白马怕青牛，羊鼠一旦休。 | 效果卡：一匹白马和一头青牛对峙、互相喷气；一只羊和一只老鼠背对背走开。 |
| **断裂** | 先生拨了拨算盘：男属马，女属鼠——子午相冲。 | 算盘珠“啪”一声；镜头冲击抖动；四根柱子中间裂开一道缝。 |
| **冷面双句** | 好消息是，每个属相都有一个“六合”的天生搭档。坏消息是，每个属相也有一个冲、一个害，还躲不开一个“刑”。 | 十二生肖站成一圈，每只身边贴着一个笑脸搭档；接着每只身后又各冒出三个皱眉的。 |
| **解释** | 合婚就像两只齿轮：齿对上了叫“合”，转得顺；齿顶上了叫“冲”，咔咔响。 | 两只大木齿轮：先顺滑咬合，再错开半齿，卡住、震动、冒木屑。 |
| **后果** | 从唐宋算起，“八字合不合”，在婚前被问了一千多年。 | 镜头拉远：同一座桥上，一队又一队穿不同朝代衣服的媒人捧着红纸走过（唐、宋、明、清）。 |
| **回扣反转** | 所以今天，两样东西处不来，我们还会说：八字不合。比如这只猫，和那只碗。 | 回到碗柜：橘猫慢慢伸爪，把碗推下柜沿——落地“哐”。猫眨眼。全片结束。 |

**角色（全部原创）：** 媒婆、男方父亲、母亲、算命先生、橘猫，以及只在画面里出现的那对年轻人（隔着河对望一眼）。
**场景：** 沿用技能模板里的河、桥和小镇结构，改成江南风格：白墙、深灰瓦、马头墙、石拱桥、红灯笼、乌篷船。
**光线：** 前半段白天；“断裂”之后切黄昏（金色逆光）；结尾回到白天的室内碗柜。

## 执行时的注意事项

- 技能原作者的规则写的是“纯英文、无字幕”。本片按中文旁白来做，字幕默认不加（见下方待确认）。
- 配音：在本容器里离线生成中文 TTS（sherpa-onnx 多语种模型，可以从 GitHub 下载），或者由你录一段 `voice.wav` 上传。
- 3D 道具：技能原版用的是 Kenney 模型包，不在仓库里，本容器也访问不了 kenney.nl。所以房子、桥、船、柱子、齿轮全部在代码里程序化生成（模板的 `build.ts` 本来就是这样生成房子的）。
- 渲染：本容器没有 GPU，WebGL 走软件渲染，速度会比原作者的电脑慢很多。先出 0.5 倍静帧确认画面，最终版视速度决定是 1080x1920 还是 2K（1440x2560）。
